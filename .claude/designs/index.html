Design principles

Dense desktop instrument24 px tree rows, 28 px grid rows, 36 px toolbars. Every pixel of chrome earns its place; panes are hairline-separated, not boxed.
Monospace-forward dataAnything that came from Postgres is set in mono with type-specific alignment and colour. UI chrome uses a humanist sans so the two never blur.
Environment colour as safetyPROD is red on the server row, the tab edge, the status bar and inside every confirm. Typed confirmation is required there for anything destructive.
Links everywhereAny string that parses as [schema_]table/id and resolves against the catalog becomes a chip — in grid cells, nested jsonb, the JSON editor, even SQL literals. Reverse references are one panel away.
Server-side truthPaging, sorting, filtering and counts run on the server; the renderer never holds more than a capped page. The generated SQL is always one click away.
No silent destructive actionsDirect-execute is reserved for reads and refreshes. Writes preview their SQL; drops, truncates and terminates go through a confirm that shows numbers and dependants.

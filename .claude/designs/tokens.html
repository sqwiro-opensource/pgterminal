Accessibility & density notes

  • Focus ring: 2 px --ring outset with 2 px offset on buttons; inset on tree rows and grid cells. Focus is never removed without a replacement.
  • Icon-only buttons carry aria-label and a 600 ms tooltip that also shows the shortcut.
  • Tree uses role=tree / treeitem, aria-expanded, aria-level, roving tabindex; grid uses role=grid with row/col indexes, arrow navigation, Home/End, PageUp/Down; selection announced via a live region.
  • Hit targets: 24×24 minimum in compact, 28×28 default; rows are full-width targets; chips pad invisibly to 24 px.
  • Colour is never the only signal: env badges carry text, pending cells carry a ✎ gutter mark, link chips carry an icon, NULL is a word.
  • Contrast ≥ 4.5:1 for all text in both themes; alt-row tint ≤ 3 % luminance so it never competes with selection.
  • Reduced motion: pulsing dots, shimmer and flashes are disabled; static state colours remain.
  • Dialogs trap focus, restore it on close, Esc closes any non-executing dialog; the typed-confirmation input is auto-focused and labelled.
  • Text scaling: the UI font-size setting applies at the root; controls use rem, hairlines use px.
